Changelog

1.2.0

  • Paste JSON
    You can now fill Metadata Tags Editor with data from JSON. Additionally, Ctrl + C and Ctrl + V support was added.

  • Menu item icons
    Added icons to all menu entries.

1.1.0

Applying changes to multiple assets at once is now smarter and will not accidentally overwrite metadata tags.
Overwrite and Append are now replaced by Clear & Overwrite and Smart Apply.

  • Clear & Overwrite
    All assets end up having exactly the same properties as visible in Metadata Tags Editor.

  • Smart Apply
    This feature compares initial metadata tags with what is visible in the editor. The editor knows which tags were added, removed, modified or left unchanged. It will apply only those changes. Thanks to it, a chance of breaking your assets metadata is much lower.
